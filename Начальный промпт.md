КИТ (меняется только этот блок)
- Название: compose-cupertino
- Репозиторий: https://github.com/alexzhirkevich/compose-cupertino
- Каталог компонентов: docs/Cupertino.md + публичные @Composable в модуле cupertino
- Зависимости: io.github.alexzhirkevich:cupertino, cupertino-icons-extended (версию проверь через klibs getLatestVersion)
- Доп. модули (adaptive, native, decompose, blur и т.п.) — только если без них не работает штатный компонент
- Тема: корневой компонент темы кита + его color scheme (light/dark); акцентный/динамический цвет — только если кит его даёт

ЗАДАЧА
Протестируй design system из блока КИТ. Весь UI только API этого кита. Никаких Material, своих кнопок, карточек, тулбаров, диалогов и кастомной отрисовки. Нет компонента в каталоге — не выдумывай и не имитируй: пропусти роль и запиши в отчёт «нет в ките».

Тестовый UI — каркас корпоративного приложения, не витрина кнопок. Внутри живут приложения разных типов: список, карточка, форма, настройки. Охват максимальный, но каждый экран — рабочий сценарий.

ОБОЛОЧКА (роли)
- один корневой scaffold кита; верхний бар с именем приложения и иконкой-кнопкой настроек из иконок кита
- основная навигация: нижнее меню, на широком экране боковое (rail), если есть
- внутри раздела вкладки или сегменты
- поиск; бейдж у пункта навигации или действия
- длинный список с pull-to-refresh
- подтверждение действия — snackbar или toast кита
- первичное действие — FAB или floating toolbar
- путь раздела — breadcrumbs
- тема только через тему кита; в настройках выбор system / light / dark, плюс динамический или акцентный цвет, если кит умеет
- выбор темы сохраняется между перезапусками в DataStore (не rememberSaveable)
- цвета и типографика только из темы кита, без хардкода

РАБОЧИЙ СТОЛ
Заголовок секции, список строк кита, карточка/секция, surface, text, divider. У строки иконка кита, заголовок и вторичный текст. По тапу открывается деталь. Пустое и загрузочное состояние — через индикатор прогресса кита.

ДЕТАЛИ И ФОРМА
Текстовое поле, switch, checkbox, radio, slider (range, если есть), picker (числа, даты, времени). Выбор из списка через dropdown, popup или action sheet. Подтверждение — диалог кита. Дополнительное действие — bottom sheet кита. Подсказка — tooltip. Кнопки и иконки-кнопки только из кита. Оверлеи используй в одном варианте, не дублируй; desktop-окна отдельно и коротко, если цель — desktop.

НАСТРОЙКИ
Экран открывается иконкой из верхнего бара. Собран из компонентов настроек кита (preference, section или list rows). Тема — через штатный switch или radio кита. Ещё нужны checkbox-строка, строка со стрелкой (link), выбор из списка, slider-строка. Цвет темы — через color picker кита, если он есть и кормит тему.

ВЁРСТКА
- один корневой scaffold; экраны внутри без своего scaffold
- если вложенный неизбежен, его content не применяет повторно padding внешнего
- отступы из paddingValues применяются ровно один раз
- у каждого экрана навигации непрозрачный фон из темы кита, применённый до padding: предыдущий экран не должен просвечивать

ЗАПРЕТ
Никакого UI вне компонентов кита. Второй design kit не подключать. Не имитировать компоненты, которых нет в каталоге. Демо-данные фейковые и короткие, только чтобы экраны были живыми.

ОТЧЁТ
