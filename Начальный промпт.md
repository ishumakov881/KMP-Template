Давай протестируем Design System miuix, https://klibs.io/project/compose-miuix-ui/miuix . подключи модули библиотеки top.yukonga.miuix.kmp для miuix-ui, miuix-preference, miuix-icons, miuix-nav. blur и squircle только если без них не обойтись штатному компоненту. весь ui только api этой библиотеки. никаких Material, своих кнопок, карточек, тулбаров, диалогов и кастомной отрисовки. если нужного компонента нет в доке http://compose-miuix-ui.github.io/miuix/components/ не выдумывай.

тестовый ui это каркас корпоративного приложения. не витрина кнопок. приложения разных типов живут внутри него. список, карточка, форма, настройки. охват максимальный, но каждый экран это рабочий сценарий.

оболочка. Scaffold, сверху TopAppBar с именем приложения и IconButton настроек из иконок miuix. основной переход NavigationBar, на широком экране NavigationRail. внутри раздела TabRow. поиск через SearchBar. у пункта навигации или действия Badge. длинный список с PullToRefresh. подтверждение действия Snackbar. первичное действие FloatingActionButton или FloatingToolbar, что есть в библиотеке. путь раздела BreadcrumbBar. тема только через MiuixTheme и ThemeController. в настройках переключатель system, light, dark, плюс monet и keyColor, если эти режимы есть в ColorSchemeMode этой версии. выбор темы сохраняется. цвета и текст только из MiuixTheme, не хардкод.

рабочий стол. SmallTitle, список из BasicComponent, Card, Surface, Text, Divider. у строки иконка miuix, заголовок, вторичный текст. открытие детали. пустое и загрузочное состояние через ProgressIndicator, не кастомный спиннер.

детали и форма. TextField, Switch, Checkbox, RadioButton, Slider, NumberPicker. выбор из списка через OverlayDropdownMenu или OverlayListPopup. подтверждение через OverlayDialog. дополнительное действие через OverlayBottomSheet. подсказка Tooltip. Button и IconButton только из библиотеки. оверлеи Scaffold Overlay*, не дублируй всё Window*. Window* отдельно, коротко, если цель desktop.

настройки. экран, который открывает иконка из TopAppBar, только из miuix-preference. тема через SwitchPreference или RadioButtonPreference, не самодельный switch. ещё CheckboxPreference, ArrowPreference, OverlayDropdownPreference или OverlaySpinnerPreference, SliderPreference или RangeSliderPreference. цвет темы через ColorPalette или ColorPicker, если они кормят keyColor в ThemeController.

запрет. не пиши ui вне компонентов библиотеки. не подключай второй design kit. не имитируй компонент, которого нет в каталоге. демо-данные фейковые и короткие, только чтобы экраны были живыми.
